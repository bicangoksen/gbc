## Week 1 - History
- Writing systems can represent many different languages
- Cuneiform was one of the earliest writing systems in history

## Week 2 - Bits and Bytes
- 1 byte = 8 bits, computers store everything as 0s and 1s
- Binary system is the foundation of all digital data

## Week 3 - Text Structure
- Plain text files store data without formatting
- File structure and encoding affect how data is read

## Week 4 - Keyboards and Editors
- Different keyboard layouts exist (QWERTY, AZERTY, etc.)
- Text editors are tools for writing and editing code or plain text

## Week 5 - CLI (Command Line Interface)
- CLI lets you control the computer using text commands
- Basic commands: cd, ls, mkdir are used to navigate folders
